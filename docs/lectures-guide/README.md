# Course lectures guide

A guide to the course lectures system added in commit `57dd383`: how content is
organized, the lectures page, the curriculum manager, prerequisite locks,
availability and archive, lecture PDF files, reports, what happened to old
content, and the fixes made afterwards (up to `c40f502`).

| File | Language |
| --- | --- |
| `lectures-guide-en.html` / `lectures-guide-en.pdf` | English |
| `lectures-guide-ar.html` / `lectures-guide-ar.pdf` | Arabic (RTL) |

The HTML files open directly in a browser (fonts load from Google Fonts). The
PDFs are A4 and were printed from the HTML with Chromium. When the lectures
system changes, update both HTML files and re-export the PDFs.

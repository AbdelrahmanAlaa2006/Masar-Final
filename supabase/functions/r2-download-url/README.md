# r2-download-url — Secure Pre-signed GET Download Delivery

This Supabase Edge Function provides authoritative, server-gated, short-lived (5-minute) pre-signed GET URLs for Cloudflare R2 files attached to lectures.

## 1. Security Guarantee
- **Authorization Before Signing:** The function resolves the file from the database using `fileId` and validates tenant isolation, lecture containment (`contextLectureId`), package subscription (`has_content_access`), and parent lecture unlock state (`check_content_unlocked`).
- **No Arbitrary Key Signing:** The client cannot supply an arbitrary `fileKey`.
- **Short-Lived Expiration:** Signed URLs expire after 300 seconds (5 minutes).

## 2. Configuration & Deployment

### Required Secrets
Reuses the exact same secrets already configured for `r2-upload-url`:
```bash
R2_ACCOUNT_ID
R2_ACCESS_KEY_ID
R2_SECRET_ACCESS_KEY
R2_BUCKET
```

### Deployment Command
From the project root:
```bash
supabase functions deploy r2-download-url
```

## 3. Production Bucket Hardening (Disabling Public Access)
Once all client flows route through `r2-download-url`:
1. Open the Cloudflare Dashboard → R2 → Select Bucket (e.g., `masaar-pdfs`).
2. Go to **Settings** → **Public Access** → **R2.dev subdomain**.
3. Toggle R2.dev subdomain to **Disabled**.
4. Result: Unsigned direct HTTP GET requests are rejected with `HTTP 401/403` at the Cloudflare edge, while pre-signed GET URLs generated by this function continue to work seamlessly until their 300s expiration.

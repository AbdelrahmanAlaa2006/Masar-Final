# بوابة الواتساب متعددة المنصات (Multi-tenant WhatsApp Gateway)

تستضيفها **مرة واحدة أنت (المطوّر)**، وبعدها كل مدرّس يربط رقم الواتساب الخاص به
**من داخل التطبيق بمسح QR فقط** — بدون أي خطوات تقنية على المدرّس، ومجاناً.

```
المدرّس (غير تقني)           التطبيق                     هذه البوابة (تستضيفها مرة واحدة)
  يضغط "ربط الواتساب"  ─▶  يعرض QR داخل الصفحة  ◀─  Baileys يولّد QR لكل منصة على حدة
  يصوّر الـ QR بهاتفه   ─────────────────────────▶  الجلسة تُحفظ، والرسائل تُرسل تلقائياً
```

## لماذا هذه الطريقة؟
- **للمدرّس غير التقني:** لا ملفات، لا terminal — فقط زر ومسح QR داخل التطبيق.
- **متعدد المنصات:** البوابة تتعرّف على المنصة من توكن تسجيل الدخول تلقائياً، وتحفظ
  جلسة واتساب منفصلة لكل منصة. لا يمكن لأي منصة رؤية رسائل غيرها.
- **مجاني وأوتوماتيكي:** لا Docker، لا اشتراك. عملية Node واحدة فقط.

## التشغيل (خطوة المطوّر — مرة واحدة)

### 1) الإعداد
```bash
cd whatsapp-gateway
cp .env.example .env      # واملأ القيم
npm install
```
في `.env` ضع:
- `SUPABASE_URL` و `SUPABASE_ANON_KEY` (نفس قيم المشروع)
- `SUPABASE_SERVICE_ROLE_KEY` (من Supabase → Project Settings → API → service_role)
  ⚠️ هذا المفتاح سري ويبقى على الخادم فقط، ولا يظهر في التطبيق إطلاقاً.

### 2) التشغيل
```bash
npm start
```
أو انشره مجاناً على **Render / Railway / Fly.io** (خدمة Node عادية، أمر التشغيل `npm start`).
> ملاحظة: يجب أن يكون للخادم **قرص دائم** لحفظ مجلد `sessions/` (جلسات الواتساب)،
> وإلا سيحتاج المدرّسون لإعادة مسح الـ QR بعد كل إعادة تشغيل.

### 3) اربط التطبيق بالبوابة
في ملف `.env` الخاص بالمشروع (الواجهة) ضع عنوان البوابة:
```
VITE_WHATSAPP_GATEWAY_URL=https://your-gateway-url.com
```
ثم أعد بناء/تشغيل التطبيق. سيظهر تلقائياً كارت **"الإرسال التلقائي المجاني"** في صفحة
رسائل أولياء الأمور.

## الأمان والعزل
- كل طلب يحمل توكن المستخدم (JWT). البوابة تتحقق منه وتستخرج `tenant_id` من التوكن
  نفسه — **لا تثق بأي معرّف منصة قادم من المتصفح**.
- فقط الأدمن (أو مساعد يملك صلاحية `whatsapp`) يمكنه الربط أو الفصل.
- مفتاح الـ service role يُستخدم داخل الخادم فقط لقراءة طابور الرسائل الخاص بكل منصة.

## الحماية من الحظر (مدمجة)
- تأخير عشوائي 25–60 ثانية بين الرسائل (لكل منصة).
- حد أقصى يومي 300 رسالة لكل منصة (قابل للتعديل في `.env`).
- مؤشر "يكتب الآن..." قبل كل رسالة.
- ⚠️ الطرق غير الرسمية تحمل دائماً نسبة خطر بسيطة. للأمان المطلق، يوجد خيار
  الواتساب الرسمي (Cloud API) في نفس الصفحة.

## نقاط النهاية (API)
| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | `/api/status` | حالة الربط + QR + عدد رسائل اليوم |
| POST | `/api/connect` | بدء جلسة وتوليد QR |
| POST | `/api/disconnect` | فصل الرقم وحذف الجلسة |
| GET | `/health` | فحص أن الخادم يعمل |
